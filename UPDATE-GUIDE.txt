সাইট আপডেট করার গাইডবুক
==========================
নিয়ম: ছবি/PDF সঠিক ফোল্ডারে রাখুন → তারপর নির্দিষ্ট ফাইলে এক লাইন লিখুন → ফাইল সেভ করে সাইটে আপলোড করুন।
ফাইলের নাম ইংরেজিতে, ফাঁকা ছাড়া রাখুন (যেমন deputation-nov-1.jpg)। ছবি ৫০০KB–১MB এর মধ্যে রাখলে সাইট দ্রুত চলে।
লাইনের শেষে কমা (,) দিতে এবং ""  '' চিহ্ন ঠিক রাখতে ভুলবেন না। ভুল হলে ওই ফাইলের সব লেখা আসবে না।

১) কর্মসূচি (ডেপুটেশন / সম্মেলন / বৈঠক / সমাজসেবা)
   ছবি রাখুন : events/        ফাইল: content.js → const EVENTS
   লাইন:  ,{id:'e6',t:'শিরোনাম',d:'2026-11-05',c:'ডেপুটেশন',img:'events/e6-1.jpg',photos:['events/e6-2.jpg','events/e6-3.jpg'],b:'বিবরণ'}
   id প্রতিটির আলাদা হতে হবে (e6, e7 ...)। নতুনটা সাইট নিজে সবার আগে দেখাবে।

২) লেখা / সম্পাদকীয়
   ফাইল: content.js → const BLOGS     লাইন: {id:'b3',t:'শিরোনাম',d:'2026-11-05',c:'সম্পাদকীয়',img:'events/b3.jpg',b:'লেখা'}

৩) ছবির ঘর (Gallery)
   ছবি রাখুন : images/         ফাইল: data.js → const GALLERY
   লাইন:  {"image":"images/nam.jpg","caption":"ক্যাপশন","category":"ডেপুটেশন"},
   category একই লিখলে একই ফিল্টারে আসবে; নতুন নাম দিলে নতুন ফিল্টার-বোতাম নিজে তৈরি হবে।

৪) মাসিক পত্রিকা
   PDF রাখুন : journal/ (যেমন issue-02.pdf), প্রচ্ছদের ছবি চাইলে journal/issue-02.jpg
   ফাইল: content.js → const JOURNAL
   লাইন:  {no:7, date:"২০২৬-১০-১৫", file:"journal/issue-02.pdf", cover:"journal/issue-02.jpg", note:"বছর ৫১ সংখ্যা ৭"},

৫) সংগ্রহশালা (সংবাদ কাটিং, চিঠি, পোস্টার, স্মারকলিপি)
   ছবি/PDF রাখুন : images/ বা events/     ফাইল: content.js → const ARCHIVE
   লাইন:  {t:'শিরোনাম',d:'2026-11-05',c:'সংবাদ',img:'images/press-xyz.jpg',file:'events/memo.pdf',b:'বিবরণ'},
   c = সংবাদ লিখলে হোমপেজের "সংবাদমাধ্যমে আমরা" অংশেও দেখাবে।

৬) জানুন › গাইডলাইন ও নথি (ওবিসি শংসাপত্র, দলিল, বাইলজ, আদেশ)
   ফাইল রাখুন : guides/obc-certificate/  guides/deed/  guides/bylaws/  guides/orders/
   ফাইল: content.js → const GUIDES
   বিদ্যমান কার্ডে ফাইল বসান:  pdf:'guides/orders/order-01.pdf', img:'guides/orders/order-01.jpg'
   নতুন আদেশ/নথি: কমেন্টে দেওয়া লাইনটি কপি করে নতুন t (নাম) ও pdf/img পথ বসান।

৭) ফোন, ইমেইল, ঠিকানা, ফর্ম লিংক, UPI, ব্যাংক, সোশ্যাল লিংক
   ফাইল: config.js (এক জায়গায় বদলালে সব পাতায় বদলে যায়)

৮) নতুন ট্যাব / মেনুর বিন্যাস
   মেনু আছে index.html এর <nav id="nv"> এ। পাঁচটি ভাগ: আমাদের পরিচয় | কার্যক্রম | তথ্য ও সহায়তা | সংবাদ ও প্রকাশনা | যোগাযোগ।
   "যোগ দিন" ও "দান" বাটন আলাদা — <div class="hact"> এ (ড্রপডাউনের ভেতরে নয়)।
   বিদ্যমান ড্রপডাউনে নতুন পাতা যোগ: ওই ভাগের <div class="dd"> এর ভেতরে একটি লাইন জুড়ুন:
        <a href="#notice">নোটিশ</a>
   নতুন পাতা বানাতে:
   ক) site.js এর  const P={  এর ভেতরে:
        notice(){return head('নোটিশ','উপশিরোনাম')+`<div class="w" style="padding:40px 20px">${cards2(NOTICES)}</div>`},
   খ) content.js এ তালিকা:  const NOTICES=[ {t:'শিরোনাম',d:'2026-11-05',c:'নোটিশ',img:'',file:'events/n1.pdf',b:'বিবরণ'} ];
   (সমস্যা হলে আমাকে বলুন — আমি করে দেব।)

আপলোডের আগে: ব্রাউজারে index.html খুলে নতুন তথ্য দেখে নিন।

৯) সহায়ক চ্যাট (নিচের ডানদিকের "প্রশ্ন করুন" বোতাম)
   ফাইল: chatbot.js → const KB। নতুন প্রশ্ন-উত্তর যোগ করতে একটি { ... }, লাইন কপি করুন:
     {id:'xyz', k:['কীওয়ার্ড১','কীওয়ার্ড২','english word'], a:()=>'উত্তর', l:()=>[['বোতামের লেখা','#পাতা']]},
   k = যে শব্দ থাকলে এই উত্তর আসবে (বাংলা + ইংরেজি/Banglish দুটোই দিন)। l = লিংক (ঐচ্ছিক)।
   সমাধান না হলে বা বোট না বুঝলে চ্যাট নিজে হোয়াটসঅ্যাপে পাঠায় (প্রশ্নটি আগে থেকে লেখা থাকে)।
   হোয়াটসঅ্যাপ নম্বর ও ফোন config.js থেকে আসে। এই চ্যাট কারও লেখা সংরক্ষণ করে না।
